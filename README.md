# Interactive Number Guessing Game 🎮

A classic, robust Command-Line Interface (CLI) Number Guessing Game developed in Python. Designed for beginners, this application demonstrates control flow, loops, pseudo-random number generation, and input exception handling.

## Features
* **Randomized Generation:** Generates a random secret number between 1 and 100 using Python's built-in `random` module.
* **Dynamic Feedback:** Provides instant hints ("Too high" or "Too low") to guide the user.
* **Attempt Tracking:** Counts and displays the exact number of guesses taken to win.
* **Error Handling:** Safely catches invalid text inputs without crashing the application.

## Technologies Used
* **Python 3.x** (`random` module)
* **Git & GitHub** (Version Control)
